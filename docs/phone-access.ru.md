# Подключить телефон по домашнему Wi-Fi

Локальная возможность версии 0.4.43. Для установленного Mac-приложения
нужна сборка, включающая это обновление.

1. Подключите Mac и телефон к одной домашней сети Wi-Fi.
2. На Mac откройте **Life Assistant → Настройки → Доступ с телефона**.
3. Нажмите **Подключить телефон**. При запросе macOS разрешите приложению
   доступ к локальной сети и входящие подключения.
4. Наведите камеру телефона на QR-код и откройте ссылку в браузере.

Устанавливать приложение на телефон не требуется. Телефон открывает ту же
квартиру, места хранения, фотографии и вещи. Новые вещи и изменения
сохраняются в базе Mac. Отдельная копия квартиры в браузере телефона не
создаётся. Меню открывается кнопкой «Меню», каталог на телефоне начинает
работу в виде плиток. Можно добавлять и редактировать вещи и фотографии.

Mac должен оставаться включённым и не спать, Life Assistant — работать.
Закрыть его окно можно: приложение продолжает работать в строке меню.
Полный выход через **⌘Q** отключает доступ. При следующем запуске его
нужно включить заново; QR-код будет новым. Работа без связи с Mac и доступ
через интернет в эту версию не входят.

QR-код содержит ключ доступа к вашим данным: показывайте его только тем,
кому хотите дать доступ. **Обновить QR-код** отключает прежние подключения
и меняет ссылку. **Выключить доступ** останавливает подключение сразу.
Вкладка может оставаться подключённой до суток; после окончания сеанса
отсканируйте актуальный код ещё раз.

Изменения с другого устройства появляются автоматически, обычно в течение
нескольких секунд. Открытую форму или редактор приложение не заменяет.
Если данные успели измениться, устаревшее сохранение отклоняется. Нажмите
**Обновить данные**, затем повторите правку на актуальных данных. Черновик
карточки сохраняется на телефоне. История отмены после получения внешних
изменений очищается, чтобы отмена не затронула чужую правку.

Если ссылка не открывается, проверьте, что Mac не спит и доступ включён.
Гостевая Wi-Fi сеть может изолировать устройства. Если у Mac несколько
адресов, выберите другой в поле «Сеть Mac». После смены сети заново откройте
настройки на Mac и отсканируйте актуальный QR-код.

Подключение использует локальный HTTP и предназначено для доверенной
домашней сети. Публичного сервера, облачной загрузки и настройки роутера нет.
