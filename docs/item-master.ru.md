# Мастер предметов

Раздел собирает действующие вещи, мебель, сумки и контейнеры из общей базы,
включая «Без места». Комнаты, встроенные секции, архив и корзина исключены.

## Поиск и применение

1. Нажмите «Найти для непроверенных» или выберите вещи и нажмите «Искать выбранные».
2. Откройте результаты вещи и выберите свою модель и комплектацию.
3. Нажмите «Сравнить и применить». Для нескольких выбранных вещей используйте
   «Сравнить выбранные».
4. Отметьте нужные поля. Заполненные значения и название в каталоге изначально
   не отмечены. После применения доступна общая отмена.

Завершённая проверка сохраняется у предмета вместе с датой, источниками и
результатами. Частичные результаты и отсутствие сведений тоже исключают его
из будущих общих поисков. Переименование, перемещение, перезапуск и отмена
применения характеристик не снимают отметку проверки. «Искать заново» запускает
повтор явно; ошибка такого повтора сохраняет предыдущие результаты.

Прерывание и ошибка сети не считаются успешной проверкой. При ошибке источника
очередь останавливается, чтобы не отправлять запросы для остальных предметов.
Кнопка «Остановить» сохраняет результаты завершённых проверок.

## Источники и ограничения

Используется общедоступная HTML-выдача DuckDuckGo без платного API или ключей.
Сначала выполняется запрос производителя (для известных брендов — по его
доменам), затем при неполных данных — общий запрос. За один поиск читается
не более восьми страниц товаров; запросы идут последовательно с паузой.
Передаются только название, бренд и модель. Фотографии, заметки, серийные номера
и место хранения не передаются. Найденные страницы не исполняются как код.

Данные читаются из Product / ProductModel в JSON-LD и простых таблиц
характеристик. Учитываются варианты ProductGroup. Не все сайты публикуют такой
формат; страницы, требующие входа, JavaScript или проверки браузера, могут быть
недоступны. Неизвестные значения не угадываются. При ограничении поиска можно
воспользоваться «Добавить ссылку» и прочитать открытую страницу товара напрямую.
Это бесплатный поиск без гарантии доступности выдачи или полноты характеристик.

На реальной проверке выдача DuckDuckGo вернула ограничение запросов; приложение
обработало его как ошибку, а не «ничего не найдено». Чтение актуальной открытой
карточки IKEA KALLAX успешно получило название и MPN как в браузерном сервере,
так и через модуль Mac. Вес коробок из этой страницы не принят за вес стеллажа.

У каждого найденного значения есть ссылка и пояснение. Из вариантов товара
данные автоматически не объединяются. SKU магазина и штрихкоды не сохраняются
как артикул производителя. Вес доставки не подставляется вместо веса предмета.
Транспортный объём берётся только из явно указанных сложенных/упакованных
габаритов либо транспортных литров. Вычисленный объём прямоугольного габарита
помечается «≈»; он не является точной оценкой заполнения сумки.

## Хранение и запуск

Результаты лежат в `node.itemResearch`, ошибка — в `node.itemResearchError`.
История связана с ID вещи, входит в общую резервную копию и не зависит от
применения полей. Перед сохранением проверяется, что идентифицирующие сведения
не изменились во время поиска; перед применением — что карточка и выбор модели
не изменились после открытия сравнения.

Применяются поля «Официальное название», «Артикул производителя», «Вес, г»,
«Транспортный объём, л». Последнее имеет приоритет в справочных объёмах поездок,
но не меняет вручную указанное заполнение сумки. Собственное название меняется
только при явном выборе соответствующего поля.

В Vite dev / preview чтение страниц обслуживает локальный модуль
`item-master-server.js`. В Mac используется `ItemMasterHTTP`, для телефона —
тот же модуль через авторизованный LAN-сеанс. Только HTTPS; запрещены локальные
и служебные IP, адреса с паролем, произвольные порты. Проверенный IP закрепляется
для запроса с сохранением TLS-проверки имени; перенаправления проверяются заново.
Ограничены время, размер ответа и число параллельных запросов.

Обычный статический хост без этого обработчика не выполняет внешний поиск.
Новая Mac-сборка требуется для появления обработчика в установленном приложении.
Локальная работа над разделом не включает установку или публикацию Mac-приложения.

Отдельная демонстрационная база открывается по
`/?section=item-master&demo=item-master`; личная база не используется.

## Проверки

- `node --test src/item-master/model.test.js src/item-master/lookup.test.js`
  из `web/`: область поиска, приватность, повторные запуски, отмена, конфликт
  изменений, несколько предметов, единицы, источники, упаковка, безопасность адресов.
- `node scripts/check-item-master-ui.cjs`: отдельный браузерный контекст,
  управляемые тестовые ответы источников, выбор модели, групповое применение,
  прямой URL, сохранение ручных значений, отмена, перезапуск, ошибки и узкий экран.
- `scripts/test-item-master-http.swift`: защита нативного чтения;
  `--live` дополнительно читает публичный пример IKEA.
- `scripts/test-inventory-lan.swift`: авторизация и сохранение общей базы.

Форматы источников: [Product](https://schema.org/Product),
[weight](https://schema.org/weight),
[HTML-поиск DuckDuckGo](https://duckduckgo.com/duckduckgo-help-pages/features/non-javascript/).
