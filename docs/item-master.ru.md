# Мастер предметов

Раздел собирает действующие вещи, мебель, сумки и контейнеры из общей базы,
включая «Без места». Комнаты, встроенные секции, архив и корзина исключены.

## Поиск и применение

Сверху расположены вкладки «Автоматический» и «Ручной». Автоматическая сохраняет
поиск и сравнение источников; счётчики сведены в одну строку, подробное пояснение
свёрнуто в «Как работает поиск», строки списка уплотнены.

1. Нажмите «Найти для непроверенных» или выберите вещи и нажмите «Искать выбранные».
2. Откройте результаты вещи и выберите свою модель и комплектацию.
3. Нажмите «Сравнить и применить». Для нескольких выбранных вещей используйте
   «Сравнить выбранные».
4. Отметьте нужные поля. Заполненные значения и название в каталоге изначально
   не отмечены. После применения доступна общая отмена.

Завершённая проверка сохраняется у предмета вместе с датой, источниками и
результатами. Частичные результаты и отсутствие сведений тоже исключают его
из будущих общих поисков. Переименование, перемещение, перезапуск и отмена
применения характеристик не снимают отметку проверки. «Искать заново» запускает
повтор явно; ошибка такого повтора сохраняет предыдущие результаты.

Прерывание и ошибка сети не считаются успешной проверкой. При ошибке источника
очередь останавливается, чтобы не отправлять запросы для остальных предметов.
Кнопка «Остановить» сохраняет результаты завершённых проверок.

## Ручное заполнение

Во вкладке «Ручной» по умолчанию показаны вещи, у которых не заполнено хотя бы
одно из четырёх полей: официальное название, артикул производителя, вес в граммах
и транспортный объём в литрах. Можно отдельно выбрать полностью пустые карточки,
конкретное отсутствующее поле или все вещи. Статус автоматического поиска
не мешает ручному заполнению. Оценочный вес мебели считается незаполненным;
явно введённый вес, в том числе из старого поля в килограммах, учитывается.

«Выбрать все без параметров» отмечает весь отфильтрованный список, включая строки
за пределами первых 60 показанных. Параметры редактируются прямо в таблице:
для разных вещей можно указать разные значения. Ввод автоматически отмечает
строку. Кнопка «Сохранить изменения» сохраняет только изменённые поля выбранных
строк одним действием с общей отменой. Снятый выбор оставляет черновик, но не
применяет его. «Сбросить черновики» отменяет несохранённый ввод.

Пустое поле с черновиком явно очищает соответствующее значение; остальные поля
не меняются. Своё название, количество и место хранения не заменяются.
Изменения выбранных полей проверяются повторно при сохранении: если карточка
изменилась с начала ввода, весь пакет отклоняется, черновики остаются.
Вес принимается числом без единиц, объём — положительным числом, десятичная
запятая разрешена. Уточнение оценочного веса снимает отметку оценки.

Черновики сохраняются в памяти при переключении двух вкладок, до сохранения
или перезагрузки страницы. Сохранённые параметры входят в общую базу.
Ручной ввод не выполняет внешние запросы, не создаёт отметку поиска и не
снимает ранее сохранённую отметку проверки.

## Подключение личного ключа Tavily

Нажмите «Подключить Tavily», скопируйте API-ключ из кабинета сервиса,
вставьте в скрытое поле и нажмите «Проверить и подключить». Проверка читает
`/usage`, не выполняя поисковый запрос. Поддерживается бесплатный тариф
Researcher / Free с лимитом до 1000 кредитов; платные тарифы и активный
лимит оплаты сверх пакета не принимаются. Неверный новый ключ не заменяет
предыдущее рабочее подключение.

Через «Настроить Tavily» можно обновить остаток, заменить или удалить ключ.
На предмет нужно до двух запросов Basic Search (один кредит на запрос).
Прежние проверки вещей сохраняются; общий поиск продолжает только непроверенные.

На Mac ключ лежит в отдельной записи Связки ключей
`local.myhome.inventory.tavily`, вне базы вещей, истории и резервных копий.
В браузерной dev/preview-версии он находится в памяти локального сервера:
перезагрузка страницы сохраняет подключение, перезапуск сервера требует
повторного ввода. В браузерное хранилище ключ не записывается. В обзорном
демо подключения нет. Телефон использует подключение Mac; ввод и удаление
ключа выполняются на Mac, чтобы не передавать ключ через домашний HTTP-сеанс.

Ключ отправляется только в Authorization на фиксированные HTTPS-адреса
`api.tavily.com/usage` и `/search`, без перенаправлений. На сайты товаров он
не передаётся. Сервер и нативный обработчик возвращают состояние и счётчики,
никогда сам ключ.

Остаток автоматически уточняется раз в две минуты; между обновлениями
запросы резервируются локально. Это оценка: другие приложения могут использовать
тот же аккаунт, а неуспешный запрос консервативно уменьшает локальный остаток
до следующей проверки. Нулевой остаток останавливает запросы с ключом.

## Источники и ограничения

Без личного ключа используется официальный бесплатный доступ Tavily без аккаунта
и карты (`X-Tavily-Access-Mode: keyless`). Этот режим имеет ограничения частоты/объёма запросов;
сервис не публикует гарантированный постоянный размер бесплатного лимита.
При ограничении очередь останавливается с понятным сообщением. Незавершённая
проверка не исключает предмет из следующего запуска. Уже найденные сведения
сохраняются, если отказал только дополнительный поиск.

Сначала выполняется запрос по официальным доменам распознанного производителя,
затем при неполных данных — общий поиск. Для неизвестного бренда сразу выполняется
общий запрос; источник показывается без неподтверждённой отметки производителя.
За один поиск читается не более восьми страниц товаров; запросы идут последовательно
с паузой. Передаются только название, бренд и модель. Фотографии, заметки,
серийные номера и место хранения не передаются. Найденные страницы не исполняются.

Данные читаются из Product / ProductModel в JSON-LD и простых таблиц характеристик.
Дополнительно читаются явно подписанные свойства из полного текста страницы,
возвращённого Tavily. Краткие поисковые выдержки и сгенерированные ответы не
используются для заполнения полей. Заголовок поисковой выдачи не считается
официальным названием. Учитываются варианты ProductGroup; общий текст не
распределяется по нескольким вариантам. Проверяется соответствие модели;
артикул в ссылке позволяет открыть страницу, но затем должен подтвердиться
в характеристиках товара.

Не все сайты доступны и не все свойства распознаются. При ограничении поиска
можно воспользоваться «Добавить ссылку» и прочитать открытую страницу напрямую.
Неизвестные значения не угадываются. Полнота характеристик не гарантируется.

25.10.2026 полный живой поиск нашёл на официальных страницах Sony вес
WH-1000XM5 — 250 г, а у IKEA KALLAX — название и артикул 906.373.03.
Вес коробок IKEA не принят за вес стеллажа. Через настоящий интерфейс отдельно
проверены поиск Sony без подмены ответов, сохранение, перезагрузка и исключение
проверенного предмета из следующего запуска. Нативный модуль тоже получил
реальные официальные страницы Sony через бесплатный поиск.

У каждого найденного значения есть ссылка и пояснение. Из вариантов товара
данные автоматически не объединяются. SKU магазина и штрихкоды не сохраняются
как артикул производителя. Вес доставки не подставляется вместо веса предмета.
Транспортный объём берётся только из явно указанных сложенных/упакованных
габаритов либо транспортных литров. Вычисленный объём прямоугольного габарита
помечается «≈»; он не является точной оценкой заполнения сумки.

## Хранение и запуск

Результаты лежат в `node.itemResearch`, ошибка — в `node.itemResearchError`.
История связана с ID вещи, входит в общую резервную копию и не зависит от
применения полей. Перед сохранением проверяется, что идентифицирующие сведения
не изменились во время поиска; перед применением — что карточка и выбор модели
не изменились после открытия сравнения.

Применяются поля «Официальное название», «Артикул производителя», «Вес, г»,
«Транспортный объём, л». Последнее имеет приоритет в справочных объёмах поездок,
но не меняет вручную указанное заполнение сумки. Собственное название меняется
только при явном выборе соответствующего поля.

В Vite dev / preview поиск и чтение страниц обслуживает локальный модуль
`item-master-server.js`. В Mac используется `ItemMasterHTTP`, для телефона —
тот же модуль через авторизованный LAN-сеанс. Только HTTPS; запрещены локальные
и служебные IP, адреса с паролем, произвольные порты. Проверенный IP закрепляется
для запроса с сохранением TLS-проверки имени; перенаправления проверяются заново.
Ограничены время, размер принимаемого ответа и число параллельных запросов.
Поисковый запрос отправляется только на фиксированный адрес `api.tavily.com/search`.

Обычный статический хост без этого обработчика не выполняет внешний поиск.
Новая Mac-сборка требуется для появления обработчика в установленном приложении.
Локальная работа над разделом не включает установку или публикацию Mac-приложения.

Отдельная демонстрационная база открывается по
`/?section=item-master&demo=item-master`; личная база не используется.

## Проверки

- `node --test src/item-master/model.test.js src/item-master/lookup.test.js src/item-master/connection.test.js src/item-master/manual-model.test.js`
  из `web/`: область поиска, приватность, повторные запуски, отмена, конфликт
  изменений, несколько предметов, единицы, источники, упаковка, безопасность адресов.
- `node scripts/check-item-master-ui.cjs`: отдельный браузерный контекст,
  управляемые тестовые ответы источников, выбор модели, групповое применение,
  прямой URL, сохранение ручных значений, отмена, перезапуск, ошибки и узкий экран.
- `node scripts/check-item-master-manual-ui.cjs`: компактность автоматического
  списка, переключение вкладок с клавиатуры, отбор пропусков, выбор 65 вещей
  при показе 60, ввод разных значений, пакетное сохранение, отмена, черновики,
  ошибка числа, перезагрузка, телефон и отсутствие поисковых запросов.
- `node scripts/check-item-master-live.mjs`: явная сетевая проверка полного
  поиска публичных моделей Sony и IKEA; необязательный аргумент `Sony` или `IKEA`.
- `node scripts/check-item-master-browser-live.cjs`: реальный поиск из отдельной
  браузерной демобазы без подмены ответов, сохранение и исключение после перезапуска.
- `scripts/test-item-master-http.swift`: защита нативного чтения;
  `--live` читает публичный пример IKEA, `--live-search` проверяет поиск Sony.
- `scripts/test-item-master-tavily.swift`: подключение, замена, остаток, кеш,
  удаление ключа и отказ платным тарифам с вымышленным хранилищем; реальная
  Связка ключей не читается. `--live-invalid` проверяет отказ настоящего Tavily
  на заведомо неверном ключе, не используя аккаунт пользователя.
- `scripts/test-inventory-lan.swift`: авторизация, сохранение общей базы,
  запрет управления ключом с телефона.
