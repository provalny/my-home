# Идеи: показатели квартиры и следующие обновления

23 октября 2026. Это предложения для обсуждения. Сбор показаний, подключения и расчёты ещё не включены в приложение. Расходы на еду исключены по просьбе пользователя.

## 1. «Расход квартиры» — счётчики и коммунальные ресурсы

Отдельный экран с месяцем, карточками электричества, холодной и горячей воды, графиком и историей показаний. Первый полезный вариант работает локально, с ручным вводом показаний; подключать аккаунты и устройства для начала не требуется.

| Показатель | Что показывать | Откуда брать |
| --- | --- | --- |
| Электричество | Расход за период в кВт·ч; дневная/ночная зоны при многотарифном счётчике; сравнение с предыдущим периодом | Показания счётчика с датой; впоследствии импорт или подключённый счётчик |
| Холодная вода | Расход в м³, при желании рядом литры | Разность показаний всех относящихся к квартире счётчиков ХВС |
| Горячая вода | Расход в м³ отдельно от ХВС | Показания счётчиков ГВС |
| Вся вода | Сумма ХВС + ГВС за одинаковый период | Расчёт по двум видам воды, без повторного прибавления отдельных счётчиков |
| Газ | Расход в м³, если он используется и есть показания | Отдельный счётчик; блок можно скрыть |
| Отопление | Гкал или кВт·ч тепла, только если есть соответствующий учёт | Фактические показания/импорт, без выдумывания расхода по температуре комнаты |
| Расчётная стоимость ресурсов | Оценка по вашим тарифам с разбивкой | Тарифы, введённые пользователем, и подтверждённый расход |

Важные различия: **кВт** — мощность в конкретный момент, **кВт·ч** — израсходованная энергия. Сумма показаний на экране счётчика — накопленный итог, а расход за период — разность показаний. 1 м³ воды = 1000 литров. Мгновенный расход воды в л/мин появляется только при наличии соответствующего датчика.

Пример: электричество 12 430 → 12 586 кВт·ч даёт 156 кВт·ч за период; ХВС 218,40 → 221,10 м³ даёт 2,70 м³; ГВС 103,20 → 104,90 м³ даёт 1,70 м³. Всего воды — 4,40 м³. Это иллюстрация расчёта, не реальные данные квартиры.

Над графиком — переключение «Этот месяц / Предыдущий / Свой период». У каждой карточки видны дата последнего показания, источник и полнота данных. Пропуски не превращаются в нули. Сравнение периодов разной длины дополнительно показывать в среднем за день; оценку неполного месяца явно помечать.

Ввод: выбрать счётчик → дата снятия → значение → сохранить. Фото показания можно прикрепить; распознавание цифр по фото — отдельное дальнейшее улучшение с подтверждением пользователем. Исправление старой записи пересчитывает зависимые периоды и сохраняется в истории. При замене счётчика начинается новая серия, а не отрицательный расход. Поддержать несколько счётчиков одного вида и тарифы с датой начала действия.

## 2. «Состояние квартиры» — климат и события

План квартиры с небольшими показателями по комнатам: температура, влажность, при наличии датчика — CO₂. Рядом события «окно открыто», «обнаружена вода», «датчик давно не обновлялся». На карточке всегда есть источник и время измерения; старое значение не выдаётся за текущее.

Пороги комфортности и уведомления пользователь настраивает сам. Автоматические измерения появятся только после явного подключения совместимых датчиков. Начать можно с ручных заметок и снимка состояния, не создавая видимость живой телеметрии.

В дальнейшем: напряжение в В и текущая мощность в Вт/кВт от совместимых устройств; расход отдельных приборов в кВт·ч только при наличии их собственного учёта. Общий расход квартиры нельзя достоверно распределить по приборам просто по мощности из карточек вещей.

## 3. «Обслуживание дома» — полезные напоминания

Замена фильтров воды, чистка кондиционера, обслуживание стиральной машины, проверка батареек датчиков, сроки поверки счётчиков из их документов. Даты и интервалы берутся из введённых пользователем сведений/документов; приложение не придумывает обязательные интервалы.

Каждое обслуживание связано с карточкой техники или счётчика: что сделано, когда, заметка и следующее напоминание. Для автомобиля позже использовать тот же принцип: сезонные шины, пробег, ТО, страхование и документы. Текущая 3D-модель кроссовера сама эти функции не включает.

## Предлагаемый порядок обновлений

| Этап | Содержание |
| --- | --- |
| 0.4.0 — локально готовится сейчас | 15 новых моделей, просмотр в 3D, размеры, варианты шин и углового дивана |
| Следующий этап: показания | Электричество, ХВС/ГВС, несколько счётчиков, история, ручной ввод и месячный расход |
| Затем: графики и обслуживание | Сравнение периодов, ваши тарифы и расчётная стоимость, обслуживание техники и счётчиков |
| Затем: подключённые данные | Согласованные интеграции, например Home Assistant; локальное хранение ключей, явный выбор источников и обработка потери связи |
| Затем: автомобиль | Карточка кроссовера, багажник как место хранения, шины, пробег и обслуживание |
| Перед стабильной версией | Проверка реальных обновлений между версиями, миграций/восстановления, работы с большим каталогом и доступности интерфейса |

Будущим этапам номера пока не назначены: состав можно изменить после обратной связи. Публикация новых сборок на GitHub приостановлена по просьбе пользователя. Отсутствие подключений не должно мешать пользоваться инвентаризацией.
