# Согласованный словарь автоматической редкости по заголовку

24 октября 2026. Подтверждено командой «делай», реализовано в 0.4.44/build50.
Пользователь попросил пройти все категории, включая синие предметы, но
основывать назначение на ключевых словах в заголовке независимо от категории.
Направления ниже нужны только для просмотра списка. Это предложения для
игровой системы инвентаризации, а не объективный рейтинг качества брендов.

## Принципы

- Источник новых правил — название предмета; категория не участвует.
- Без совпадения — белый. Зелёный — базовые названия предметов.
- Ручной выбор сохраняет приоритет. Точная модель/фраза важнее общего
  бренда; среди одинаково точных совпадений — более высокий уровень.
- Целые слова, без учёта регистра. Дефисы и варианты написания нормализуются;
  русские названия брендов добавляются явно. MOZART не совпадает с MOZA.
- Pro, Ultra, Premium, «профессиональный», «лимитированный» и «коллекционный»
  по отдельности не повышают редкость.
- Аксессуар в заголовке распознаётся отдельно от техники, для которой он
  предназначен: «чехол для Leica» получает уровень чехла, «Leica M11» — камеры.
- Серый предлагается оставить ручным: поломка/износ не меняют редкость сами.

Уже согласовано: DJI/Canon/Sony/Apple/Audeze — фиолетовые; Leica/MOZA и
Audeze LCD-4/LCD-5 — оранжевые. Типы редакторских MacBook, трипл-кокпита и
двух 3D-принтеров уже дают фиолетовый независимо от переименования.
Все дополнительные варианты ниже подтверждены. Основная логика теперь
использует только заголовок. MacBook также распознаётся по названию.

фиолетовый Nord; они включены в словарь. MacBook распознаётся по заголовку.

## Зелёные кандидаты

Книга, блокнот, ежедневник, термос, рюкзак, чехол, настольная лампа,
сковорода, кастрюля, полотенце, плед, набор отвёрток, коврик для йоги.
Предусмотреть словарь форм: книга/книги, полотенце/полотенца и т. п.

## Дополнительные легендарные кандидаты

- Фото и кино: Hasselblad, Phase One, ARRI.
- Звук: STAX SR-X9000, Focal Utopia, Sennheiser HE 1.
- Часы: часы Rolex, часы Patek Philippe, часы Audemars Piguet.
- Музыка: рояль Steinway.
- Коллекции: сочетание «первое издание» и «автограф» в одном названии.

Оранжевый не требуется для каждого направления. Новые кандидаты не
подменяют уже согласованные Leica, MOZA и Audeze LCD-4/LCD-5.
