# История изменений Life Assistant

При каждом завершённом обновлении пользовательского приложения обновляй
`web/src/inventory/releases.json`: новую запись ставь первой, прежние сохраняй.
Эта история показывается пользователю по кнопке «Что нового».
Пиши по-русски, кратко: что добавлено, изменено или исправлено; без имён файлов,
технических журналов и ещё не реализованных обещаний. Не включай правки только документации.

Начальная версия — 0.0.1. По правилу пользователя от 23 октября 2026 обычные
обновления, включая новые возможности, увеличивают только третье число на 1.
Второе число меняй исключительно по явной команде пользователя для особо
глобальных функций. Первое число самостоятельно не меняй. Ранее выпущенные
версии задним числом не перенумеровывай. Номер `build` растёт
при каждом таком обновлении. Версия меняется за завершённый набор изменений,
а не за каждую правку файла. Дата записи — дата готовности обновления.

Версия интерфейса и приложения macOS берётся из первой записи этого JSON.
Не меняй версию формата данных инвентаризации ради версии приложения.
`CHANGELOG.md` относится к исходному House Control; историю нашего приложения веди отдельно.
