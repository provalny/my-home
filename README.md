# Мой дом — инвентаризация для macOS

Локальная версия на основе [House Control](https://github.com/0xProbabillity/house-control), MIT. Сохраняет 3D-сцену, визуальный стиль и редактор планировки оригинала. Собирается отдельным приложением с большим окном и собственным идентификатором `local.myhome.inventory`. Исходный README сохранён в `UPSTREAM_README.md`.

## Запуск

Готовое приложение: **build/Мой дом.app**. Открыть двойным нажатием. Для работы не нужны браузер, Terminal, аккаунт или интернет. На этом Mac сборка для Apple silicon; минимальная версия macOS — 13. Приложение подписано локально (ad hoc), не нотарифицировано для распространения.

При первом запуске создаётся новая демонстрационная квартира. Главный экран — обзор имущества. Нажмите комнату или мебель на 3D-плане, чтобы увидеть содержимое. Встроенный редактор открывается кнопкой «Редактор»: после изменений нажмите «Сохранить план», затем «Закрыть редактор».

## Первая версия

- Одна квартира с комнатами. Мебель, отсеки и вложенные коробки; вещи на любом уровне. Мебель сама имеет карточку и цену.
- Быстрая форма и «Создать ещё», копирование отдельной карточки, одно фото, готовые характеристики по категории.
- Категории и подкатегории с созданием и переименованием. Каталог, фильтры, поиск по характеристикам и полному адресу (⌘K).
- Перенос отдельных вещей и групп; контейнер перемещается с содержимым. Перетаскивание вещей на места хранения. Для порядка отсеков перетащите ручку «Порядок» на другой отсек.
- Архив с причиной, датой и суммой продажи; для заполненного контейнера выбор судьбы содержимого. Восстановление из архива.
- Покупная цена, текущая оценка, износ и заполненность задаются вручную. В общей сумме каждая карточка считается один раз; цена партии расходников задаётся за всю партию.
- История покупок, перемещений, изменения стоимости, архива. Сводка покупок, продаж и списаний по месяцам.
- Сроки годности и гарантии внутри приложения; уведомления macOS включаются пользователем в настройках. Интервал по умолчанию 3 дня. Работа в фоне после закрытия окна, включаемый автозапуск.
- Автокопия ежедневно при работающем приложении в выбранную папку; **последние 5 копий**. После сна или выключения пропущенная копия создаётся при следующей проверке. Ручной экспорт и восстановление; до восстановления — защитная копия.

В v1 островок выключен. Мониторинг, автомобиль и личные метрики представлены будущими разделами. Подключение к умному дому не используется. Исходники дополнительных платформ House Control сохранены для будущей работы, но целевой исполняемый файл HomeInventory их не подключает.

## Хранение

`~/Library/Application Support/MyHomeInventory/inventory.json` — атомарно записываемый версионированный документ с планом, всеми карточками, фото и историей. `preferences.json` — выбранная папка автокопий и системные настройки. Каждая запись проверяет ревизию, поэтому устаревшее изменение не перезаписывает новое.

Автокопии создаются в подпапке «Мой дом — автокопии» выбранного каталога. Ротация затрагивает только файлы автокопий нашего приложения. Ручные экспорты и защитные копии не входят в лимит 5. Защитные копии перед восстановлением сохраняются рядом с основной базой.

Копия содержит фотографии и все данные, максимум импорта — 100 МБ. Проверка импорта отклоняет циклы, потерянные адреса, неподдерживаемые версии, неверные суммы и даты. Удаление мебели с плана сохраняет инвентаризацию; при удалении комнаты её содержимое переносится в первую оставшуюся комнату.

## Сборка и проверки

Нужны Swift Command Line Tools, Node.js 22.12+ и pnpm 11.

```sh
cd web
pnpm install --frozen-lockfile
pnpm test
cd ..
bash scripts/build-inventory.sh
```

Проверка нативного сохранения и ротации копий:

```sh
swiftc macos/Sources/HomeInventory/InventoryStore.swift scripts/test-inventory-store.swift -o /tmp/home-inventory-store-checks
/tmp/home-inventory-store-checks
```

`HOUSE_DATA_DIR` задаёт отдельную папку для проверки приложения без доступа к рабочим данным. `HOUSE_SNAPSHOT_DIR` сохраняет PNG главного окна после запуска. Для веб-разработки `cd web && pnpm dev`, адрес `http://127.0.0.1:5199/`. Браузерный просмотр хранит данные в браузере; нативные функции папок, уведомлений и автозапуска доступны в .app.

## Устройство проекта

- `web/src/inventory/model.js` — чистая модель данных, адреса, операции, валидация и демо.
- `web/src/inventory/app.js`, `inventory.css` — интерфейс инвентаризации в стиле House Control.
- `web/src/three/`, `web/src/editor/` — 3D-сцена и адаптированный редактор оригинала.
- `macos/Sources/HomeInventory/` — отдельная оболочка AppKit/WKWebView, сохранение, копии и уведомления.
- `docs/inventory-requirements.ru.md` — согласованные ответы на 30 вопросов и исходные решения.
